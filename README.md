# Расписание преподавателей

**Поиск пар по фамилии прямо в браузере.** Данные читаются из публичной Google Таблицы, бэкенд не нужен.

[**Открыть →**](https://d1m40fficial.github.io/teacher-schedule/)

## Что умеет

- загружает четыре листа (`1–4 курс`) как CSV через Google Sheets `gviz`;
- ищет преподавателя по фамилии, открывает вкладки и запоминает их на время сессии;
- группирует пары по дням, показывает курс, группу, время и аудиторию;
- помечает дистанционные занятия и практику;
- светлая и тёмная темы;
- целиком статический сайт: HTML + CSS + vanilla JS.

## Как это работает

Каждый лист Google Таблицы отдаётся как CSV:

```text
https://docs.google.com/spreadsheets/d/<id>/gviz/tq?tqx=out:csv&sheet=1%20курс
```

Страница разбирает строки, находит заголовки групп, дни и пары. Никакого SheetJS и бинарного XLSX.

## Запуск

Откройте `index.html` через любой статический сервер (из-за CORS):

```bash
python -m http.server 5185
```

Затем `http://localhost:5185/`.

## Деплой

GitHub Pages публикует ветку `main` из корня. Файл `.nojekyll` уже добавлен.

## Ограничения

- Google Таблица должна быть доступна по ссылке;
- структура листов предполагает текущую сетку пар;
- расписание зависит от внешнего источника и не кешируется между сессиями.
